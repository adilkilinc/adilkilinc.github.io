How it works

The model is two-dimensional, in plane stress, meshed with incompatible-mode quadrilaterals (QM6) that stay accurate in bending even with few elements through the depth. As on a testing machine, loading is displacement-controlled: you impose the movement of the grip or the free end, and the analysis returns the force and the stresses.

The material is linear elastic, so one solve per configuration is enough and everything else follows by proportion. The point marked on the curve is first yield. Beyond it the elastic analysis no longer represents the material, and regions where the von Mises stress exceeds the yield strength turn red.

Limits

  • No plasticity yet: beyond first yield the analysis stays elastic.
  • No buckling: in compression this linear model cannot buckle.
  • No torsion: it is a three-dimensional problem, beyond a plane model.
  • Indicative material properties: do not use them to size a part.
